# 🔥 Diablo Chat

Anonymous real-time chat application built with Node.js, Express, and Socket.IO.

## Features

- ✅ Anonymous chat - No signup/login required
- ✅ Real-time messages - Instant delivery via WebSockets
- ✅ User presence - See who's online
- ✅ Typing indicators - See when someone types
- ✅ Dark theme - Modern Diablo aesthetic
- ✅ Mobile PWA - Installable on phone
- ✅ Works offline - After first load

## Setup

```bash
# Install dependencies
npm install

# Start server
npm start
```

Open `http://localhost:3000` in your browser.

## Deployment (Railway)

1. Push to GitHub
2. Connect repo to [Railway](https://railway.app)
3. Railway auto-deploys on push

## Install on Phone (PWA)

1. Open the app URL in Chrome (Android) or Safari (iOS)
2. Tap menu → "Add to Home Screen"
3. The app icon appears on your home screen

## Tech Stack

- **Backend**: Node.js + Express + Socket.IO
- **Frontend**: Vanilla HTML/CSS/JS
- **Hosting**: Railway.app
